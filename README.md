# 봄바람교회 (BomBaram Church) 공식 홈페이지

복음으로 사람과 세상을 새롭게 보는 온라인 공동체, 봄바람교회의 공식 홈페이지입니다.

- 사이트: https://jaeh312.github.io/bombaram-church/
- 구성: 단일 페이지 `index.html` (Tailwind CSS CDN, Pretendard/Noto Sans KR 웹폰트)
- 로고: `assets/logo-color.png` (컬러), `assets/logo-white.png` (화이트 반전)

## 수정 방법

`index.html`을 고친 뒤 `main` 브랜치에 push하면 GitHub Pages에 자동 반영됩니다(반영까지 1분 내외).
